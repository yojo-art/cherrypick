# HTL ではチャンネルアカウントのノートを配信しない

ホーム／ソーシャル TL と fanout 再取得では、チャンネル投稿の正規の配信単位は一般ユーザーが書いた投稿本体だけとする。チャンネルアカウントのノート（純粋リノートの展開経路を含む本体投稿）は送らない。同一ノート ID の Streaming 重複を避け、REST／連合テストが既に期待する「チャンネルアカウント作者の行は HTL に出ない」と揃えるため。欠落時にリノートだけで救出する例外は持たない。リモート実装がチャンネル名義の告知やピン関連の投稿を送ってきても HTL には出さず、チャンネル画面・プロフィール側の関心事とする（#1181 の範囲外）。
